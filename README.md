## 🌟 About The Project

**Food Recipe App** is a responsive web application built using HTML, CSS, and JavaScript. It allows users to discover recipes from different cuisines and search for their favourite meals using the [TheMealDB API](https://www.themealdb.com/).

The application features a clean, modern interface with an elegant food-inspired design, making recipe exploration simple and enjoyable.

## ✨ Features

- 🔍 **Search Recipes:** Find meals by entering a recipe name.
- 🌍 **Explore Cuisines:** Browse recipes from different countries.
- 🍛 **Multiple Categories:** Indian, Canadian, American, Thai, British, and Russian cuisines.
- ⚡ **API Integration:** Fetch recipe data from TheMealDB.
- 📱 **Responsive Design:** Optimized for desktop and mobile screens.
- 🎨 **Interactive UI:** Smooth scrolling, hover effects, and attractive recipe cards.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/fatima-rizwan/Food-Recipe-App.git
```

**2. Navigate to the project folder**

```bash
cd Food-Recipe-App
```

**3. Open the project**

Open `index.html` in your browser or use the VS Code Live Server extension.

No additional installation or setup is required.
